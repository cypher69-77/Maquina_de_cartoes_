# Maquina_de_cartoes_
meu primeiro projeto em python, consiste em uma maquina de cartões completa.

atualmente funciona apenas no terminal.

o programa possui: 

sistema de loguin,
recurso para criação de contas,
sistema de escolha de formas de pagamento,
calculo automático de preços com taxas que são pre-definidas no loguin,
resultado,
opção de desfazer loguin,

alterações futuras:

registro de vendas,
integração a bancos de dados MySql,
interface grafica,
sistema de dia e horas.
